# 🏛️ Dual-AI Trading Arena

نظام تداول متقدم يجلب بيانات حية من Polymarket ويحللها باستخدام Claude و Gemini.

## ✨ المميزات

- **جلب بيانات حية من Polymarket**: الاتصال المباشر مع Gamma API
- **تحليل ذكي ثنائي**: Claude Haiku و Gemini Flash
- **معايير تداول صارمة**: التحقق من السيولة والوقت المتبقي
- **واجهة عربية كاملة**: RTL Layout مع دعم شامل
- **API endpoints**: للتكامل مع أنظمة أخرى

## 🚀 البدء السريع

```bash
# 1. استنساخ المشروع
git clone https://github.com/mad321/polymarket-bot.git
cd polymarket-bot

# 2. تثبيت المكتبات
pip install -r requirements.txt

# 3. إعداد المفاتيح
cp .env.example .env
# عدّل .env وأضف المفاتيح

# 4. التشغيل
python app.py
```

التطبيق يعمل على: **http://localhost:5000**

## 📚 الملفات الرئيسية

- `app.py` - تطبيق Flask الرئيسي
- `config.py` - الإعدادات والثوابت
- `polymarket_service.py` - خدمة Polymarket API
- `ai_analysis.py` - تحليلات Claude و Gemini
- `requirements.txt` - المكتبات المطلوبة

## 🔔 تنبيهات تيليجرام

المراقب يفحص الصفقات كل 30 ثانية، ويرسل تنبيهاً عندما يصل السعر لوقف الخسارة أو الهدف. هو لا يبيع بنفسه أبداً. البيع يتم فقط عندما تضغط زر البيع وتؤكده (انظر "زر البيع في تيليجرام").

1. في تيليجرام افتح **@BotFather** وأرسل `/newbot`، ثم اختر اسماً للبوت. سيعطيك رمزاً (token) مثل `123456:ABC...`.
2. افتح البوت الجديد واضغط **Start**.
3. افتح في المتصفح `https://api.telegram.org/bot<الرمز>/getUpdates` بعد وضع رمزك مكان `<الرمز>`، وانسخ الرقم الذي بعد `"chat":{"id":`.
4. في Render أضف `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` في Environment ثم احفظ.

بعد إعادة التشغيل تصلك رسالة "✅ مراقب بوليماركت بدأ العمل". إذا تكررت هذه الرسالة كثيراً فالخادم ينام ويستيقظ، والمراقب لا يعمل وهو نائم.

لمعرفة حالة المراقب افتح `/api/alerts/status`. الصفحة تعرض هل المراقب يعمل، ومتى فحص آخر مرة، وآخر خطأ في الإرسال. لا تظهر فيها أي رموز سرية.

إعدادات اختيارية: `ALERT_COOLDOWN` (ثوانٍ قبل تكرار تنبيه نفس الصفقة، الافتراضي 3600)، `STARTUP_ALERT=0` لإيقاف رسالة البدء، `ALERT_TZ` (الافتراضي `Asia/Riyadh`).

ملاحظة عن واتساب: إذا ضبطت `WHATSAPP_TOKEN` و`PHONE_NUMBER_ID` و`RECIPIENT_PHONE` يرسل البوت لواتساب أيضاً. لكن واتساب لا يوصل الرسائل النصية إلا خلال 24 ساعة من آخر رسالة أرسلتها أنت للرقم، لذلك تيليجرام أضمن.

## 🔴 زر البيع في تيليجرام

البوت يستطيع بيع صفقات **محفظة البوت فقط** (حساب بوليماركت منفصل فيه مبلغ صغير)، وفقط بعد أن تضغط "بيع الآن" ثم "تأكيد البيع". لا يشتري أبداً، ولا يلمس حسابك الرئيسي.

**الإعدادات في Render (Environment):**

| المتغير | القيمة |
| - | - |
| `TRADING_WALLET` | عنوان محفظة بوليماركت لحساب البوت (من قائمة الملف الشخصي في polymarket.com) |
| `TRADING_PRIVATE_KEY` | المفتاح السري لحساب MetaMask الذي يملك حساب البوت. **لا تضعه أبداً في الكود أو GitHub** |
| `TRADING_ENABLED` | `1` لإظهار أزرار البيع (الافتراضي: معطّل) |
| `TRADING_DRY_RUN` | `0` لإرسال أوامر حقيقية. الافتراضي `1`: وضع تجربة يحاكي البيع دون إرسال أي أمر |

**كيف يعمل:**

1. تنبيهات صفقات محفظة البوت يأتي معها زر **🔴 بيع الآن**. ويمكنك أيضاً إرسال `/positions` لعرض كل صفقات محفظة البوت مع زر لكل صفقة.
2. عند الضغط يحسب البوت أقل سعر يُباع به كل الأسهم الآن، ويعرض المبلغ المتوقع مع زر **✅ تأكيد البيع**، وهو صالح لدقيقتين.
3. عند التأكيد يرسل أمر بيع فوري بحد أدنى للسعر: يبيع ما يمكن بيعه بهذا السعر أو أفضل، ويلغي الباقي. لا يبيع أبداً تحت السعر الذي أكدته.

البوت يرد فقط على `TELEGRAM_CHAT_ID`، ويتجاهل أي ضغطة قديمة وصلت والخادم متوقف. وإذا كان المفتاح لا يملك المحفظة المحددة يرفض العمل ويخبرك بالسبب.

صفحة `/api/alerts/status` تعرض حالة التداول: هل هو مفعّل، وهل في وضع التجربة، وآخر عملية بيع، وآخر خطأ. لا تظهر فيها المفاتيح ولا عنوان المحفظة.

ملاحظة: خوادم Render في دول يسمح فيها بوليماركت **بإغلاق الصفقات (البيع) فقط**، لذلك لا يمكن الشراء من هذا الخادم أصلاً.
