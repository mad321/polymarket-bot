# 📊 مراقب صفقات بوليماركت

بوت يراقب صفقاتك المفتوحة في بوليماركت، ويرسل تنبيهاً في تيليجرام عندما يصل السعر لوقف الخسارة أو الهدف، ويبيع صفقات محفظة البوت بعد تأكيدك من تيليجرام.

## ✨ ماذا يفعل

- **مراقبة المحافظ:** يقرأ الصفقات المفتوحة كل 30 ثانية من Data API v2، لمحفظة `WALLET_ADDRESS` ومحفظة البوت `TRADING_WALLET`.
- **تنبيهات تيليجرام:** عند وقف الخسارة أو الهدف. انظر "تنبيهات تيليجرام".
- **زر البيع:** لصفقات محفظة البوت فقط، وبعد تأكيد. انظر "زر البيع في تيليجرام".
- **الصفحات:** `/` تعرض الصفقات، و`/api/positions` تغذي لوحة Lovable، و`/api/alerts/status` تعرض حالة المراقب والتنبيهات والتداول.

## 🚀 التشغيل محلياً

```bash
git clone https://github.com/mad321/polymarket-bot.git
cd polymarket-bot
pip install -r requirements.txt
cp .env.example .env   # ثم عدّل القيم
python polymarket_bot.py
```

التطبيق يعمل على: **http://localhost:5000**

⚠️ لا تشغّل نسخة محلية بنفس `TELEGRAM_BOT_TOKEN` الذي يستخدمه Render: النسختان تتنافسان على أوامر تيليجرام وضغطات الأزرار. للتجربة محلياً اترك `TELEGRAM_BOT_TOKEN` فارغاً، أو أضف `ENABLE_MONITOR=0` لتشغيل الصفحات فقط بدون المراقب ومستقبل الأوامر.

## 📚 الملفات الرئيسية

| الملف | الدور |
| - | - |
| `polymarket_bot.py` | تطبيق Flask: الصفحات وواجهات API، ويشغّل المراقب ومستقبل أوامر تيليجرام في الخلفية |
| `polymarket_monitor.py` | يفحص الصفقات كل 30 ثانية ويرسل التنبيهات |
| `positions.py` | يقرأ صفقات المحافظ من Data API v2 ويطبق إعدادات `config.json` |
| `alerts.py` | الإرسال إلى تيليجرام، وإلى واتساب إن كانت إعداداته موجودة |
| `telegram_actions.py` | أوامر تيليجرام وأزرار البيع |
| `trading.py` | البيع من محفظة البوت عبر مكتبة بوليماركت الرسمية |
| `config.json` | إعدادات اختيارية لكل سوق: الاسم، وقف الخسارة، الهدف، الإخفاء |

ملفات النسخة السابقة (Dual-AI Trading Arena) ما زالت في المستودع، لكن التطبيق الحالي لا يستخدمها: `ai_analysis.py` و`polymarket_service.py` و`config.py`. دليلها في [README_TRADING.md](README_TRADING.md).

## 🔑 متغيرات البيئة

| المتغير | الاستخدام |
| - | - |
| `WALLET_ADDRESS` | المحفظة التي تُراقب صفقاتها، ويمكن وضع عدة محافظ مفصولة بفواصل |
| `TELEGRAM_BOT_TOKEN`، `TELEGRAM_CHAT_ID` | التنبيهات وأوامر تيليجرام (انظر "تنبيهات تيليجرام") |
| `TRADING_WALLET`، `TRADING_PRIVATE_KEY`، `TRADING_ENABLED`، `TRADING_DRY_RUN` | زر البيع (انظر "زر البيع في تيليجرام") |

القائمة مع أمثلة في `.env.example`.

## 🔔 تنبيهات تيليجرام

المراقب يفحص الصفقات كل 30 ثانية، ويرسل تنبيهاً عندما يصل السعر لوقف الخسارة أو الهدف. هو لا يبيع بنفسه أبداً. البيع يتم فقط عندما تضغط زر البيع وتؤكده (انظر "زر البيع في تيليجرام").

1. في تيليجرام افتح **@BotFather** وأرسل `/newbot`، ثم اختر اسماً للبوت. سيعطيك رمزاً (token) مثل `123456:ABC...`.
2. افتح البوت الجديد واضغط **Start**.
3. افتح في المتصفح `https://api.telegram.org/bot<الرمز>/getUpdates` بعد وضع رمزك مكان `<الرمز>`، وانسخ الرقم الذي بعد `"chat":{"id":`.
4. في Render أضف `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` في Environment ثم احفظ.

بعد إعادة التشغيل تصلك رسالة "✅ مراقب بوليماركت بدأ العمل". إذا تكررت هذه الرسالة كثيراً فالخادم ينام ويستيقظ، والمراقب لا يعمل وهو نائم.

لمعرفة حالة المراقب افتح `/api/alerts/status`. الصفحة تعرض هل المراقب يعمل، ومتى فحص آخر مرة، وآخر خطأ في الإرسال. لا تظهر فيها أي رموز سرية.

إعدادات اختيارية: `ALERT_COOLDOWN` (ثوانٍ قبل تكرار تنبيه نفس الصفقة، الافتراضي 3600)، `STARTUP_ALERT=0` لإيقاف رسالة البدء، `ALERT_TZ` (الافتراضي `Asia/Riyadh`).

ملاحظة عن واتساب: إذا ضبطت `WHATSAPP_TOKEN` و`PHONE_NUMBER_ID` و`RECIPIENT_PHONE` يرسل البوت لواتساب أيضاً. لكن واتساب لا يوصل الرسائل النصية إلا خلال 24 ساعة من آخر رسالة أرسلتها أنت للرقم، لذلك تيليجرام أضمن.

## 🔴 زر البيع في تيليجرام

البوت يستطيع بيع صفقات **محفظة البوت فقط** (حساب بوليماركت منفصل فيه مبلغ صغير)، وفقط بعد أن تضغط "بيع الآن" ثم "تأكيد البيع". لا يشتري أبداً، ولا يلمس حسابك الرئيسي.

**الإعدادات في Render (Environment):**

| المتغير | القيمة |
| - | - |
| `TRADING_WALLET` | عنوان محفظة بوليماركت لحساب البوت (من قائمة الملف الشخصي في polymarket.com) |
| `TRADING_PRIVATE_KEY` | المفتاح السري لحساب MetaMask الذي يملك حساب البوت. **لا تضعه أبداً في الكود أو GitHub** |
| `TRADING_ENABLED` | `1` لإظهار أزرار البيع (الافتراضي: معطّل) |
| `TRADING_DRY_RUN` | `0` لإرسال أوامر حقيقية. الافتراضي `1`: وضع تجربة يحاكي البيع دون إرسال أي أمر |

**كيف يعمل:**

1. تنبيهات صفقات محفظة البوت يأتي معها زر **🔴 بيع الآن**. ويمكنك أيضاً إرسال `/positions` لعرض كل صفقات محفظة البوت مع زر لكل صفقة.
2. عند الضغط يحسب البوت أقل سعر يُباع به كل الأسهم الآن، ويعرض المبلغ المتوقع مع زر **✅ تأكيد البيع**، وهو صالح لدقيقتين.
3. عند التأكيد يرسل أمر بيع فوري بحد أدنى للسعر: يبيع ما يمكن بيعه بهذا السعر أو أفضل، ويلغي الباقي. لا يبيع أبداً تحت السعر الذي أكدته.
4. أسواق المباريات المباشرة تؤخر التنفيذ بضع ثوانٍ. في هذه الحالة يرد البوت أولاً بأن الأمر قُبل، ثم يرسل رسالة ثانية خلال دقيقة: هل بِيع وبكم، أو أنه لم يُبع لأن السعر نزل تحت الحد الأدنى.

البوت يرد فقط على `TELEGRAM_CHAT_ID`، ويتجاهل أي ضغطة قديمة وصلت والخادم متوقف. وإذا كان المفتاح لا يملك المحفظة المحددة يرفض العمل ويخبرك بالسبب.

صفحة `/api/alerts/status` تعرض حالة التداول: هل هو مفعّل، وهل في وضع التجربة، وآخر عملية بيع، وآخر خطأ. لا تظهر فيها المفاتيح ولا عنوان المحفظة.

ملاحظة: خوادم Render في دول يسمح فيها بوليماركت **بإغلاق الصفقات (البيع) فقط**، لذلك لا يمكن الشراء من هذا الخادم أصلاً.

## 🌐 النشر على Render

- Render ينشر تلقائياً كل دمج في فرع `monitor-branch`.
- أمر التشغيل يُضبط في إعدادات الخدمة (**Settings → Start Command**)، وRender لا يقرأ ملف `Procfile`. الخدمة الحالية تعمل بخادم Flask المدمج (Werkzeug)، أي بأمر مثل `python polymarket_bot.py`.
- **عملية واحدة فقط:** التطبيق يشغّل المراقب ومستقبل أوامر تيليجرام داخل نفس العملية، وتيليجرام لا يسمح إلا بمستقبل واحد لكل رمز. إذا استخدمت gunicorn فبعامل واحد فقط، كما في `Procfile`: `gunicorn --workers 1 ... polymarket_bot:app`.
- على الخطة المجانية ينام الخادم بعد 15 دقيقة بلا زيارات، ويتوقف المراقب معه. منبّه خارجي يزور `/health` كل 5 دقائق يبقيه يعمل.
